# Governance

Lyonoyl Mail is run by its maintainers. They decide what the product does, which changes are accepted, and when a release is made.

- **Every change follows [the working contract](AGENTS.md).** A change that breaks it is not accepted, whoever proposes it.
- **Changes arrive as pull requests,** are reviewed, and are merged as one commit made by the product once `scripts/preflight.sh`, run by a maintainer on the branch, is green.
- **A contribution is licensed under [Apache-2.0](LICENSE)**, as its section 5 provides, and a pull request that states other terms is not merged.
- **The name and the icon are the project's marks.** Section 6 of the license grants no right to use them as marks, so a modified build is distributed under a name and an icon of its own.
- **Sponsors and donations are the maintainers' alone.** They choose which sponsors stand in the README and change the wallets on [the donation page](docs/donations/README.md); a pull request touching either is not merged. A sponsor's logo says who supports the project, and nothing about the sponsor's product.
- **Only the maintainers publish a release** as the project's, signed and notarized.
- **Security reports** follow [the security policy](SECURITY.md), and conduct follows [the code of conduct](CODE_OF_CONDUCT.md).
