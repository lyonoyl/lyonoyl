# Security

## Reporting a vulnerability

Report it privately, through GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**. Please do not open a public issue or a pull request for it—a hole described in public is published before its fix.

Say what is affected, how to reproduce it, and what it lets somebody do. A message that triggers it is the most useful thing to attach; replace every real name and address in it first.

## What happens next

The maintainers keep the report private until a fix ships, and the release that carries the fix says what it closed. A report that is not a flaw is closed with the reason. There is no promised response time.

## Supported versions

The latest release. An older copy is fixed by updating it.

## Scope

What Lyonoyl Mail defends against, and what it does not, is in [the threat model](docs/security/threat-model.md), and every defense with what holds it is in [the defenses](docs/security/defenses.md).
