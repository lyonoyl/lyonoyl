# Sponsors

The organizations that support Lyonoyl Mail are shown in the README's Corporate Sponsors section, each with the badge of its level.

| Badge | Level | What it means |
| --- | --- | --- |
| ![Founding Patron](badges/founding-patron.svg) | Founding Patron | Supported Lyonoyl Mail before its first release |
| ![Grand Patron](badges/grand-patron.svg) | Grand Patron | The highest level of financial support |
| ![Patron](badges/patron.svg) | Patron | The level of financial support below Grand Patron |
| ![Friend of the Cat](badges/friend-of-the-cat.svg) | Friend of the Cat | The level of financial support below Patron |
| ![Supporting Organization](badges/supporting-organization.svg) | Supporting Organization | An organization that supports the project, with money or otherwise |
| ![Technology Partner](badges/technology-partner.svg) | Technology Partner | Gives the project technology or a service it is built with |
| ![Community Partner](badges/community-partner.svg) | Community Partner | Helps the project reach the people it is for |
