# Getting help

- **A problem:** open an issue with the *A problem* form. Say what you did, what you expected, and what happened, and attach the log—Settings → Storage → *Show the log folder*. The log holds no message, address, or password, and it shows when Lyonoyl Mail ran; never paste a message, an address, or a password into an issue.
- **A question:** open an issue with the *A question* form.
- **An idea:** open an issue with the *An idea* form. A change larger than a fix starts there, so that what it does is agreed before the work is done.
- **A security flaw:** report it privately, as [the security policy](SECURITY.md) says, and not in an issue.
- **Building from source:** the [development guide](docs/development/guide.md).

The maintainers answer as they can; there is no promised response time. What reaches the project from your copy is in [the privacy page](PRIVACY.md).
